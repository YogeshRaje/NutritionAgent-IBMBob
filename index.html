🥗 NutritionAgent

Personalised, AI-powered nutrition planning built with IBM Granite LLM. Ethical, helpful, and medically responsible.

View on GitHub Sample Plan

✨ Key Features

Everything you need for responsible, personalised AI nutrition planning

🤖

IBM Granite LLM

Powered by ibm/granite-3-8b-instruct via IBM watsonx.ai — enterprise-grade AI with responsible defaults.

👤

Personalised Profiles

Collects name, age, diet preference, medical history, location, and health goals for tailored plans.

🛡️

Guardrails & Safety

Input/output guardrails block harmful advice. Refuses extreme diets, dangerous keywords, and medication dosing.

⚖️

AI Ethics (HAM)

Helpful, Accurate, Mindful — embedded in every prompt. Respects dietary culture, religion, and individual needs.

💊

Medical Condition Awareness

Special handling for diabetes, hypertension, heart disease, thyroid, celiac, and more — with appropriate disclaimers.

💾

Markdown Export

Every generated plan is automatically saved as a timestamped .md file in the nutrition_plans/ folder.

🌍

Location-Aware

Suggests locally and seasonally available foods based on the user's city and country for practical, affordable advice.

🧪

LLM Testing Suite

Full pytest test suite covering accuracy, safety, guardrails, edge cases, and response correctness.

🔄 Agentic AI SDLC

All 8 phases of the AI System Development Lifecycle, applied end-to-end

Phase 1

Requirements & Ethics

Defined user stories, HAM ethics principles, guardrail requirements, and medical disclaimer policy.

Phase 2

Data & Knowledge Design

Identified user profile schema: name, age, diet, medical history, location, goal. Defined knowledge boundaries.

Phase 3

Model Selection

Selected IBM Granite 3 – 8B Instruct for its safety-tuned, instruction-following capabilities on IBM watsonx.ai.

Phase 4

Prompt Engineering

Crafted structured system prompts encoding HAM principles, contextual user profiles, and output format templates.

Phase 5

Guardrails & Safety

Implemented input filtering (harmful keywords), output post-processing, and refusal messaging.

Phase 6

Integration & Build

Built modular Python app: config, LLM client, user intake, plan generator, CLI entry point, .bat launcher.

Phase 7

Testing & Validation

LLM testing suite: accuracy, guardrail effectiveness, HAM compliance, edge cases, medical condition handling.

Phase 8

Deployment & Monitoring

Deployed to GitHub with CI-ready structure, README, .env template, requirements.txt, and .gitignore.

⚖️ AI Ethics & HAM Principles

Responsible AI built into every layer of the application

🤝

Helpful

Practical, actionable advice tailored to each user's unique profile and health goals.

🎯

Accurate

Evidence-based nutritional science. IBM Granite grounds responses in established guidelines.

🙏

Mindful

Respects dietary preferences, cultural background, religious practices, and individual sensitivities.

🛡️

Safe

Guardrails block dangerous advice. Never recommends extreme restriction, harmful substances, or medical treatments.

🔍

Transparent

Clearly identifies as AI, acknowledges limitations, and always recommends professional consultation.

⚕️

Medical Disclaimer

Every generated plan includes a prominent disclaimer. AI advice ≠ medical advice.
